# Prueba Técnica Frontend - Flujo de Contratación

## Descripción

Proyecto desarrollado como prueba técnica Frontend utilizando React.  
La aplicación replica un flujo de contratación basado en un diseño proporcionado en PDF, compuesto por diferentes pasos para selección de plan, datos personales, tipo de línea, portabilidad, aceptación de términos y pantalla final de confirmación.

El objetivo principal del proyecto es demostrar organización de componentes, estructura clara del código, maquetación responsive básica y buenas prácticas de desarrollo en React.

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- CSS
- Git / GitHub
